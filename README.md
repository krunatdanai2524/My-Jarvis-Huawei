# MY JARVIS v1.1 • Huawei Edition

เว็บแอปต้นแบบสำหรับ Huawei MatePad 11 (HarmonyOS 4.2) สร้างเพื่อทดลองใช้คำสั่งภาษาไทยและตรวจสอบความสามารถด้านเสียงของเบราว์เซอร์

## สิ่งที่ทำได้
- พิมพ์คำสั่ง เช่น "จาร์วิส เปิด Canva", "เปิด Classroom", "เปิด Drive", "บอกเวลา", "บอกวันที่"
- คำสั่ง "จดบันทึก ..." จะเก็บข้อความในเบราว์เซอร์เครื่องนั้นผ่าน localStorage
- บันทึก/ส่งออกข้อความ และดูประวัติคำสั่งล่าสุด
- ทดสอบไมโครโฟน การรับเสียง และเสียงพูดตอบ (ขึ้นกับ Huawei Browser)
- มีไฟล์ manifest และ service worker เพื่อรองรับการเพิ่มไปยังหน้าจอหลัก และใช้งานบางส่วนออฟไลน์

## เผยแพร่ผ่าน GitHub Pages
1. เปิด Settings ของ Repository
2. ที่แถบด้านซ้ายเลือก Pages
3. ใน Build and deployment เลือก Source: Deploy from a branch
4. เลือก Branch: main และโฟลเดอร์ /(root) จากนั้นกด Save
5. เปิด https://krunatdanai2524.github.io/My-Jarvis-Huawei/

## ใช้งานบน Huawei MatePad 11
1. เปิดลิงก์เว็บไซต์ด้วย Huawei Browser (ต้องเป็น HTTPS)
2. ทดลองพิมพ์ "บอกเวลา"
3. แตะ "ทดสอบสิทธิ์ไมโครโฟน" แล้วอนุญาต
4. แตะ "ทดสอบเสียงตอบ" และ "เริ่มพูดคำสั่ง"
5. หากเบราว์เซอร์ไม่รองรับ Web Speech API ให้ใช้คำสั่งพิมพ์แทน
6. ใช้เมนูเบราว์เซอร์เพื่อเพิ่มทางลัดไปยังหน้าจอหลัก (ชื่อเมนูแตกต่างตามรุ่น)

## ความปลอดภัยและข้อจำกัด
- โค้ดนี้ไม่เก็บหรือส่ง API key
- แผงบันทึกเก็บข้อมูลในเบราว์เซอร์ของผู้ใช้ ไม่ได้อัปโหลดโน้ตไปยัง GitHub
- หากล้างข้อมูลเว็บไซต์หรือเปลี่ยนเครื่อง บันทึกอาจหาย ควรส่งออกเป็นไฟล์สำรอง
- ไม่ใช่ LLM; ตอบรับเฉพาะคำสั่งที่โปรแกรมรู้จัก
- ไม่สามารถควบคุม Windows ผ่านอินเทอร์เน็ตได้ในรุ่นนี้
- การรู้จำเสียง/สังเคราะห์เสียงในบางเบราว์เซอร์อาจใช้บริการคลาวด์ของผู้ให้บริการเบราว์เซอร์
- โปรดอย่าใส่ข้อมูลส่วนตัวของนักเรียนหรือข้อมูลลับลงใน Repository สาธารณะ
