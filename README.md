# MY JARVIS v1.2 • Huawei Edition

เว็บแอปคำสั่งภาษาไทยสำหรับ **Huawei MatePad 11 / HarmonyOS 4.2** เปิดใช้งานผ่าน GitHub Pages โดยไม่ต้องมี API key

## เว็บไซต์
https://krunatdanai2524.github.io/My-Jarvis-Huawei/

## วิธีสั่งงานด้วยเสียงไทย (ทดลอง)
1. เปิดเว็บผ่าน **HTTPS** บน Huawei Browser
2. ในหัวข้อ “สั่งงานด้วยเสียงบน Huawei” แตะ **1. เตรียมระบบฟังเสียงไทย**
3. ระบบจะดาวน์โหลดโมเดล **Whisper Tiny แบบหลายภาษา** ประมาณ 40–60 MB (รวมไฟล์ประกอบอาจมากกว่า) จาก Hugging Face ผ่านอินเทอร์เน็ตครั้งแรก โมเดลจะถูกแคชโดยเบราว์เซอร์หากพื้นที่เพียงพอ
4. เมื่อขึ้นว่า “Whisper พร้อมใช้งาน” แตะ **2. เริ่มอัดเสียงคำสั่ง**
5. อนุญาตสิทธิ์ไมโครโฟน พูดว่า “จาร์วิส บอกเวลา” จากนั้นแตะ **หยุดและแปลงเสียง** หรือรอให้หยุดหลัง 10 วินาที
6. เมื่อระบบถอดเสียงสำเร็จ ข้อความจะส่งเข้า Jarvis โดยอัตโนมัติ

**หมายเหตุ:** การรู้จำเสียงเกิดขึ้นในเบราว์เซอร์ผ่าน WebAssembly; เสียงดิบไม่ถูกส่งไปยังเซิร์ฟเวอร์ในโปรแกรมนี้ แต่การโหลดไลบรารีและโมเดลต้องเชื่อมต่อ CDN และ Hugging Face ครั้งแรก การทำงานบน Huawei Browser / CPU ยังต้องทดสอบจริง อาจทำงานช้า ไม่พอหน่วยความจำ หรือไม่รองรับโมดูล Worker

ถ้าโหลดโมเดลหรือเปิดไมโครโฟนไม่สำเร็จ:
- ตรวจสิทธิ์ไมโครโฟนที่เบราว์เซอร์และดูสถานะบนจอ
- ใช้ช่องพิมพ์คำสั่ง หรือการพูดแทนการพิมพ์จากแป้นพิมพ์ของแท็บเล็ต (หากมี)
- ลองเบราว์เซอร์อื่นที่รองรับ WebAssembly / Module Workers บนเครื่องเดียวกัน

## คำสั่งที่รู้จัก
- “จาร์วิส เปิด Canva”, “เปิด Google Drive”, “เปิด Classroom”, “เปิด Gmail”, “เปิด Docs”, “เปิด Sheets”
- “บอกเวลา”, “บอกวันที่”, “วิธีสั่งงาน”
- “จดบันทึก เตรียมเอกสาร IEP”, “อ่านบันทึก”

ผู้ใช้ยังต้องแตะลิงก์ที่ปรากฏสำหรับเปิดเว็บไซต์บางแห่ง เมื่อเบราว์เซอร์ป้องกันป๊อปอัปจากคำสั่งที่ส่งผ่านการรู้จำเสียง

## ระบบตอบเสียง
Huawei Browser ของเครื่องที่ใช้ทดสอบไม่พบ Web Speech Synthesis API / เสียงที่ติดตั้ง จึงใช้ไฟล์คำทักทาย MP3 ใน `assets/jarvis-greeting-th.mp3` ซึ่งใช้งานได้ตามผลทดสอบของผู้ใช้ แต่ **ยังไม่ใช่ระบบ TTS สำหรับคำตอบแบบเปลี่ยนแปลงได้** 

## โครงสร้างไฟล์
- `index.html` / `styles.css` : Dashboard
- `app.js` : ตัวแปลคำสั่งและสมุดบันทึก
- `voice-local.js` : จับเสียงจากไมโครโฟนและส่งข้อความให้ระบบคำสั่ง
- `stt-worker.js` : โหลด Transformers.js + โมเดล Whisper Tiny ใน Worker เพื่อประมวลผลภายในเครื่อง
- `sw.js` : PWA / แคชไฟล์หน้าเว็บ
- `assets/jarvis-greeting-th.mp3` : คำทักทายภาษาไทยแบบ MP3

## ความปลอดภัย
- ไม่มีการฝัง API key ใน JavaScript หรือ Repository สาธารณะ
- บันทึกข้อความเก็บใน localStorage ของเบราว์เซอร์ ไม่ส่งขึ้น GitHub
- ไม่ควรใส่ข้อมูลผู้เรียนที่มีความอ่อนไหวหรือข้อมูลราชการลับในระบบที่ไม่ได้รับอนุญาต
- ยังไม่เชื่อมต่อ LLM, ไม่สามารถใช้ Jarvis ควบคุม Windows จากภายนอก และไม่สามารถทำงานอัตโนมัติแทนทุกอย่าง
- โมเดลอาจถอดเสียงผิดหรือสร้างคำที่ไม่ได้พูด ควรตรวจสอบข้อความก่อนการดำเนินการสำคัญ
